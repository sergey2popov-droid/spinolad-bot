## Техническая основа

### Стек

- [x] Первый формат: гибрид **Node.js Telegram-бот + HTML/CSS/JavaScript Mini App прототип**.
- [x] `src/` - логика приложения.
- [x] `data/` - JSON-карточки.
- [x] `public/` - HTML/CSS/JS Mini App.
- [x] `scripts/` - проверка данных и webhook.
- [x] `.env.example` - пример переменных без секретов.
- [ ] `.env` - локальные секреты, не коммитить.

### `.env`

- [ ] `TELEGRAM_BOT_TOKEN` - токен бота от BotFather.
- [ ] `APP_BASE_URL` - публичный HTTPS URL приложения.
- [ ] `DATABASE_URL` - будущая база данных, если уйдем от JSON.
- [ ] `ADMIN_SECRET` - защита служебных endpoint'ов.
- [ ] `NODE_ENV` - `development` или `production`.

### Команды

- [x] `npm run check` - проверить JSON-базу.
- [x] `npm run ask -- "лен"` - проверить движок ответа в консоли.
- [x] `npm run dev` - запустить локальный сервер.
- [x] `npm run set:webhook` - установить Telegram webhook после заполнения `.env`.
