Технические данные

Стек

  • ✓Node.js для API, Telegram webhook и движка ответов
  • ✓HTML/CSS/JavaScript для Mini App прототипа
  • ✓JSON база: симптомы, средства, упражнения, источники
  • ✓.env.example подготовлен без секретов

.env

  • TELEGRAM_BOT_TOKEN - токен от BotFather
  • APP_BASE_URL - публичный HTTPS URL
  • DATABASE_URL - будущая база данных, если уйдем от JSON
  • ADMIN_SECRET - защита служебных endpoint'ов
  • NODE_ENV - development или production

Команды и деплой

  • ✓npm run check - проверка данных
  • ✓npm run ask -- "лен" - проверка движка
  • ✓npm run dev - локальный сервер
  • Выбрать хостинг: Vercel, Render или Railway
  • Настроить HTTPS URL для Telegram Mini App
  • Установить webhook: npm run set:webhook
